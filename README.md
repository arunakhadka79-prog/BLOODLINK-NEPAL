# BloodLink Nepal 🩸
### "Connect Donors. Save Lives."

## About the Project
BloodLink Nepal is a web-based blood donor management platform 
that connects blood donors with patients during emergencies in Nepal.

## Problem Statement
Finding blood quickly during emergencies in Nepal is chaotic. 
People rely on Facebook posts and phone calls with no guarantee of success.

## Our Solution
A platform where:
- Donors register with blood group and location
- Patients post urgent blood requests
- Nearby matching donors get notified instantly
- Blood bank directory is available

## Technologies
- Frontend: React.js, HTML, CSS, Tailwind CSS
- Backend: Node.js, Express.js
- Database: MongoDB
- Design: Figma, Canva
- Deployment: GitHub Pages + Render
